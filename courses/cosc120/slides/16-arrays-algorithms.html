Array Algorithms

COSC120: Introduction to Computer Science I

Learning Outcomes

  • Compute the sum, average, and range of an array’s elements using the accumulator pattern
  • Find the minimum and maximum by initializing to arr[0] and looping from index 1
  • Implement linear search that returns the index of a match, or -1 if not found
  • Apply multi-pass algorithms — traverse the array more than once to combine results
  • Manipulate an array in place: reverse elements using a temporary variable

Everything Starts with the Loop

Every array algorithm follows the same skeleton:

for (int i = 0; i < arr.length; i++) {
    // do something with arr[i]
}

The only thing that changes is what you do inside the loop — accumulate, compare, search, or swap. Master the loop skeleton; the algorithms snap into place.

This is a deliberate callback to deck 15. Students have already seen this loop — now they’re going to use it as a foundation for a toolkit of algorithms. Frame each algorithm as “same loop, different body.”

Sum and Average

Sum: accumulator pattern on an array:

int[] scores = {88, 74, 91, 65, 78};

int sum = 0;
for (int i = 0; i < scores.length; i++) {
    sum = sum + scores[i];
}
IO.println("Sum: " + sum);   // Sum: 396

Average: divide after the loop, not inside:

double avg = (double) sum / scores.length;
IO.println("Average: " + avg);   // Average: 79.2

Note

Cast sum to double before dividing — otherwise Java does integer division and truncates the decimal.

The cast is important: sum / scores.length in pure int arithmetic gives 79, not 79.2. (double) sum forces floating-point division. A common alternative is to declare sum as a double from the start. Either works — show both briefly. Average MUST be computed after the loop, not during: you need the full sum and the full count before dividing.

Finding Minimum and Maximum

Initialize to the first element. Then loop from index 1.

int max = scores[0];            // "current champion"
int min = scores[0];

for (int i = 1; i < scores.length; i++) {   // start at 1
    if (scores[i] > max) { max = scores[i]; }
    if (scores[i] < min) { min = scores[i]; }
}

IO.println("Max: " + max);   // 91
IO.println("Min: " + min);   // 65

Range (spread of the data):

IO.println("Range: " + (max - min));   // 26

Emphasize “start with scores[0], loop from 1” — this avoids the pitfall of initializing to 0 (next slide). You can find both min and max in a single pass. Range = max - min is a common descriptive statistic; straightforward once you have both values.

Why NOT Initialize to Zero?

Wrong approach:

int max = 0;    // ✗ what if all scores are negative?
Array Correct max Wrong max (starts at 0)
{88, 74, 91} 91 91 (accidentally correct)
{-5, -12, -3} -3 0 ← wrong!
{0, 0, 0} 0 0 (accidentally correct)

Rule: always initialize min and max to arr[0], not to 0 or any arbitrary value.

Show this table — the second row is the killer counterexample. Students often say “but my test cases work!” — yes, because they used positive numbers. The real-world lesson: test with negative values and edge cases. The fix is always the same: start at the actual first element.

Linear Search

Find the index of a value, or -1 if absent:

int target = 91;
int foundAt = -1;

for (int i = 0; i < scores.length; i++) {
    if (scores[i] == target) {
        foundAt = i;
    }
}

if (foundAt != -1) {
    IO.println("Found at index " + foundAt);   // Found at index 2
} else {
    IO.println(target + " not in array.");
}

Note

-1 is the standard “not found” signal — it can never be a real array index, so it’s unambiguous.

Linear search visits every element in sequence. This version (without break) will find the LAST occurrence if the value appears multiple times. For most intro problems, that’s fine. The -1 sentinel is a real-world convention: Java’s own String.indexOf() returns -1 for not found, so students will see this idiom again.

Multi-Pass Algorithms

Some problems need two separate passes over the array.

Example: find the maximum score, then count how many students tied for that maximum.

Pass 1 — find the max:

int max = scores[0];
for (int i = 1; i < scores.length; i++) {
    if (scores[i] > max) { max = scores[i]; }
}

Pass 2 — count ties:

int tieCount = 0;
for (int i = 0; i < scores.length; i++) {
    if (scores[i] == max) { tieCount++; }
}

IO.println(tieCount + " student(s) scored " + max);

Why two passes? You can’t count “how many equal the max” until you know what the max IS. The first pass determines the answer to “what is the max?”; the second pass uses that answer. This is the fundamental reason multi-pass algorithms exist: some information only becomes available after a full traversal.

Swapping Two Elements

To reverse or rearrange an array, you need to swap two elements. The wrong way:

arr[0] = arr[4];   // arr[0] is lost before we save it!
arr[4] = arr[0];   // now both are the same value

The right way — use a temporary variable:

int temp = arr[0];   // save arr[0] before overwriting
arr[0] = arr[4];     // overwrite arr[0]
arr[4] = temp;       // put the saved value into arr[4]

The cup/glass pouring analogy is universal and concrete. You can’t pour juice from glass A into glass B without spilling A’s juice unless you use a third empty glass first. Temp is that third glass. Walk through the three assignments line by line, tracking what each variable holds after each step.

Reversing an Array In Place

Walk inward from both ends, swapping pairs:

int[] arr = {1, 2, 3, 4, 5};

int left = 0;
int right = arr.length - 1;

while (left < right) {
    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;
    left++;
    right--;
}

// arr is now {5, 4, 3, 2, 1}
Before After swap left right
1,2,3,4,5 5,2,3,4,1 1 3
5,2,3,4,1 5,4,3,2,1 2 2
— (left = right, stop) 2 2

Walk through the table. Two pointers move inward simultaneously; when they meet in the middle, every pair has been swapped. For odd-length arrays, the middle element doesn’t need to be swapped (left == right → loop exits). In-place means no second array is needed — the work happens inside the original.

Code Example — Array Statistics

void printStats(int[] arr) {
    // Sum and average
    int sum = 0;
    for (int i = 0; i < arr.length; i++) { sum += arr[i]; }
    double avg = (double) sum / arr.length;

    // Min and max
    int min = arr[0], max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] < min) { min = arr[i]; }
        if (arr[i] > max) { max = arr[i]; }
    }

    IO.println("Sum: " + sum + ", Avg: " + avg);
    IO.println("Min: " + min + ", Max: " + max + ", Range: " + (max - min));
}

void main() {
    int[] scores = {88, 74, 91, 65, 78};
    printStats(scores);
}

Point out += as shorthand for sum = sum + arr[i]. Also note that min and max are found in a single second loop — both comparisons run for every element. This code combines sum/average, min/max, and range in one clean method.

Common Mistakes

Warning

Initializing min/max to 0 Works for positive arrays by accident. Fails for arrays containing negatives. Always use arr[0].

Warning

Starting the min/max loop at i = 0 after initializing to arr[0] Compares arr[0] against itself in the first iteration — harmless but redundant. Start at i = 1.

Warning

Swapping without a temp variable One value is overwritten and lost. Always use a temp.

Warning

Dividing before the loop is done sum / arr.length inside the loop gives the average so far, not the final average. Divide after the loop.

These four mistakes are very predictable on exams and homeworks. Have students trace through each “wrong” version to see what incorrect output it produces — error-spotting is a skill that only develops with practice.
