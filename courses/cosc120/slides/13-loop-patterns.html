Loop Patterns

COSC120: Introduction to Computer Science I

Learning Outcomes

  • Implement the accumulator pattern to compute a running total, product, or maximum
  • Implement the counter pattern to count elements that satisfy a condition
  • Implement the sentinel pattern to loop until a special input value signals termination
  • Combine accumulator and counter patterns in a single loop to solve multi-goal problems
  • Identify which loop pattern applies to a given problem

What Is a Pattern?

A loop pattern is a reusable template — the same loop shape works for many different problems.

Think of it like a cookie cutter: the cutter doesn’t care what flavor of dough you use. You just press and cut.

Pattern What it does
Accumulator Builds up a value iteration by iteration
Counter Counts how many iterations satisfy a condition
Sentinel Runs until a special “stop” value appears

Frame this deck as building a toolkit. Students already know the mechanics from decks 11–12; now they’re learning to NAME the shapes. Naming patterns matters: it lets you talk about code, recognize problems faster, and write solutions without starting from scratch each time.

The Accumulator Pattern

Template:

type result = <identity>;    // initialize BEFORE the loop

for (...) {
    result = result <op> nextValue;    // update each iteration
}

// use result AFTER the loop

Three variations:

Goal Identity Operation
Sum 0 +
Product 1 *
Concatenation "" + (String)

The “identity” value is the one that leaves the result unchanged: 0 + anything = anything; 1 * anything = anything; “” + anything = anything. Starting with the wrong identity gives a wrong answer (e.g., starting a product at 0 always gives 0).

Accumulator: Sum and Product

Sum of user inputs:

int sum = 0;

for (int i = 1; i <= 5; i++) {
    String input = IO.readln("Enter number " + i + ": ");
    int n = Integer.parseInt(input);
    sum = sum + n;
}

IO.println("Total: " + sum);

Product (factorial):

int product = 1;            // identity for multiplication

for (int i = 1; i <= 5; i++) {
    product = product * i;
}

IO.println("5! = " + product);   // 5! = 120

Walk through the sum example with a concrete run: if the user enters 3, 7, 1, 4, 2, the running sum is 0→3→10→11→15→17. Then contrast with product — same structure, different identity and operator. Ask students what would happen if product started at 0.

Accumulator: Maximum

Finding the largest value requires a slightly different identity:

String first = IO.readln("Enter number 1: ");
int max = Integer.parseInt(first);    // start with the first value

for (int i = 2; i <= 5; i++) {
    String input = IO.readln("Enter number " + i + ": ");
    int n = Integer.parseInt(input);
    if (n > max) {
        max = n;        // update only when a new champion is found
    }
}

IO.println("Maximum: " + max);

Note

For maximum, there is no numeric identity — starting at 0 would break if all inputs are negative. Start with the first element instead.

The “running champion” mental model: only the current best holds the trophy; it gets handed off whenever a bigger contender shows up. Starting at 0 is wrong if inputs can be negative (-5 > 0 is false, so -5 would never become max). Starting with the first element is always safe.

The Counter Pattern

Template:

int count = 0;             // always starts at 0

for (...) {
    if (someCondition) {
        count = count + 1; // increment only when condition is met
    }
}

// use count AFTER the loop

Example: Count how many numbers from 1 to 100 are divisible by 7:

int count = 0;

for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0) {
        count++;
    }
}

IO.println("Divisible by 7: " + count);   // 14

The counter is an accumulator where the operation is always +1 and it’s conditional. Point out that count always starts at 0 — unlike max which starts at the first element. Also a good moment to reinforce i % 7 == 0 as the divisibility test (remainder is 0 → divides evenly).

The Sentinel Pattern

Template:

// Read once BEFORE the loop (prime the pump)
String input = IO.readln("...");

while (!input.equals(SENTINEL)) {
    // process input
    input = IO.readln("...");   // read again at the BOTTOM
}

Example: Read numbers until the user types "done", print each:

String line = IO.readln("Enter a number (or 'done'): ");

while (!line.equals("done")) {
    int n = Integer.parseInt(line);
    IO.println("You entered: " + n);
    line = IO.readln("Enter a number (or 'done'): ");
}

IO.println("Finished.");

Repeat the “prime the pump” explanation from deck 11. The sentinel pattern almost always uses while (not for) because you don’t know in advance how many iterations there will be. The two reads are easy to forget — drill the pattern: read → check → use → read → check → …

Sentinel: Input Validation Loop

A sentinel loop can also enforce valid input:

String input = IO.readln("Enter a positive number: ");
int n = Integer.parseInt(input);

while (n <= 0) {
    IO.println("That's not positive. Try again.");
    input = IO.readln("Enter a positive number: ");
    n = Integer.parseInt(input);
}

IO.println("Got it: " + n);

The “sentinel” here is not a special value — it’s an invalid condition.

This is a very common real-world use case: keep asking until the answer is acceptable. Note that the structure is identical to the sentinel pattern — read before the loop, check, process (in this case, complain), read again at the bottom.

Combining Patterns: Average

Goal: read numbers from the user until "done", then print the average.

int sum = 0;      // accumulator
int count = 0;    // counter

String line = IO.readln("Enter a number (or 'done'): ");

while (!line.equals("done")) {
    int n = Integer.parseInt(line);
    sum = sum + n;    // accumulate
    count++;          // count
    line = IO.readln("Enter a number (or 'done'): ");
}

if (count > 0) {
    IO.println("Average: " + (sum / count));
} else {
    IO.println("No numbers entered.");
}

Average = sum / count. You need BOTH an accumulator (for the total) and a counter (for how many). They run in the same loop body — the loop visits each value once, and both patterns update in the same pass. The guard (count > 0) prevents division by zero if the user types “done” immediately.

Multi-Goal Loop

A single loop can track sum, count, and maximum all at once:

int sum = 0;
int count = 0;
int max = Integer.MIN_VALUE;   // smallest possible int

String line = IO.readln("Enter a number (or 'done'): ");

while (!line.equals("done")) {
    int n = Integer.parseInt(line);
    sum = sum + n;
    count++;
    if (n > max) { max = n; }
    line = IO.readln("Enter a number (or 'done'): ");
}

IO.println("Sum: " + sum + ", Count: " + count + ", Max: " + max);

Note

Integer.MIN_VALUE is the smallest int Java can represent (~−2 billion). It is always safe as the starting max because any real input will be larger.

Integer.MIN_VALUE solves the “what if all inputs are negative?” problem cleanly. Walk through a concrete example: inputs -3, -7, -1. If max started at 0, the answer would be 0 (wrong). With MIN_VALUE, it correctly finds -1.

Identifying the Pattern

When you see a loop problem, ask these questions:

  1. Do I need to build up a value? → Accumulator (sum, product, max)
  2. Do I need to count how many meet a condition? → Counter
  3. Do I not know how many iterations there will be? → Sentinel (while)
  4. Do I need both a total AND a count? → Both, same loop

Walk through the decision tree slowly. Many real problems combine two or more patterns — average is accumulator + counter, grade stats is accumulator + counter + max. Learning to spot each pattern independently is the first step to composing them correctly.

Code Example — Grade Statistics

void printStats(int numStudents) {
    int sum = 0;
    int count = 0;
    int max = Integer.MIN_VALUE;

    for (int i = 1; i <= numStudents; i++) {
        String input = IO.readln("Enter grade for student " + i + ": ");
        int grade = Integer.parseInt(input);
        sum = sum + grade;
        count++;
        if (grade > max) { max = grade; }
    }

    IO.println("Average: " + (sum / count));
    IO.println("Highest: " + max);
    IO.println("Total students: " + count);
}

void main() {
    printStats(5);
}

This example puts everything together: a method with a parameter (deck 09), a for loop (deck 12), and three loop patterns running simultaneously (accumulator for sum, counter for count, max tracker). Walk through it line by line and have students identify which part of the loop body belongs to which pattern.
