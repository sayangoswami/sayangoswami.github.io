Common Exam Patterns

The most frequently tested skills in intro CS finals:

Trace a program — given code, write the output line by line. Variable tables help.

Find the bug — given broken code, identify the error and fix it.

Write a method — given a description and method signature, fill in the body.

Write a class — given a description, write the fields, constructor, and one or two methods.

Predict and explain — given null, reference semantics, or scope, predict behavior and justify why.

Walk through each pattern explicitly. Students often study by reading notes — that’s passive. Exam performance comes from active recall: writing code from scratch, tracing unfamiliar code, explaining behavior in words. Encourage practice on past worksheets without looking at answers first.

Review: Methods

// void method with parameters
void printLine(String label, int value) {
    IO.println(label + ": " + value);
}

// method with return value
int doubleIt(int n) {
    return n * 2;
}

// method calling another method
void printDoubled(int n) {
    int result = doubleIt(n);
    printLine("Doubled", result);
}

Q: What does printDoubled(7) print?

Walk through printDoubled(7): calls doubleIt(7) → returns 14 → stores in result → calls printLine(“Doubled”, 14) → prints “Doubled: 14”. This is basic composition — the kind of tracing that appears on every intro CS exam. Make sure students can trace method calls step by step, including following the return value back to the caller.

Review: Loops + Arrays

int[] scores = {72, 85, 91, 58, 77};

int passing = 0;
int sum     = 0;

for (int i = 0; i < scores.length; i++) {
    sum += scores[i];
    if (scores[i] >= 60) { passing++; }
}

IO.println("Average: " + (double) sum / scores.length);
IO.println("Passing: " + passing + "/" + scores.length);

Q: Trace the loop. What are the final values of sum and passing?

sum = 72+85+91+58+77 = 383. passing: 72≥60 yes, 85≥60 yes, 91≥60 yes, 58≥60 no, 77≥60 yes → 4. Average = 383/5 = 76.6. Passing: 4/5. Walk through the trace table if needed. This combines accumulator + counter in a single loop (deck 13) with an array (deck 15).

Review: Classes + Objects

class Circle {
    double radius;

    Circle(double radius) { this.radius = radius; }

    double area()        { return Math.PI * radius * radius; }
    boolean isUnit()     { return radius == 1.0; }
}

Q: What does each line print?

Circle c1 = new Circle(5.0);
Circle c2 = new Circle(1.0);
IO.println(c1.area());      // ?
IO.println(c2.isUnit());    // ?
IO.println(c1.isUnit());    // ?
c1.radius = 1.0;
IO.println(c1.isUnit());    // ?

c1.area() = π * 25 ≈ 78.54. c2.isUnit() = true (radius 1.0 == 1.0). c1.isUnit() = false (radius 5.0 ≠ 1.0). After c1.radius = 1.0, c1.isUnit() = true. Walk through each line. Ask: “Does changing c1.radius affect c2.radius?” No — independent objects.
