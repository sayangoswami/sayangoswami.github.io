Arrays: Basics

COSC120: Introduction to Computer Science I

Learning Outcomes

  • Explain what an array is and describe the problem it solves
  • Declare and initialize a one-dimensional array using new int[n] or initializer syntax {...}
  • Access and modify array elements using zero-based index notation, including arr[arr.length - 1] for the last element
  • Loop over an array using for (int i = 0; i < arr.length; i++) to read or write every element
  • Apply array algorithms — sum, max, min, linear search, count — using accumulator and counter patterns
  • Identify the cause of an ArrayIndexOutOfBoundsException and correct it

The Problem Without Arrays

Storing five test grades needs five separate variables:

int grade0 = 88;
int grade1 = 74;
int grade2 = 91;
int grade3 = 65;
int grade4 = 78;

Storing grades for 30 students means 30 variables. Looping over them is impossible — you can’t write grade + i.

Open with the pain. Ask students: “How would you compute the average of 30 grades declared like this?” They can’t — each variable has a unique name, so there’s no way to refer to them systematically. Arrays solve exactly this problem: give a collection of same-type values a single name, and refer to each by its position.

The Mailbox Analogy

Imagine a row of numbered mailboxes in an apartment building:

  • Every mailbox holds one letter (one value)
  • All mailboxes hold the same type of mail (same type)
  • The building has a fixed number of mailboxes (fixed length)
  • Mailboxes are numbered starting at 0 (zero-based index)

An array is that row of mailboxes — a single named container holding many values of the same type.

The physical image matters. Zero is the first mailbox because it is 0 steps from the front of the row — the index is an OFFSET, not a count. This is why the last mailbox is always one less than the total: 5 boxes → last index is 4. Come back to this image whenever students get confused about indexing.

Declaring an Array

int[] scores = new int[5];
Part Meaning
int[] Type: an array of int values
scores Name of the array variable
new int[5] Create a new array with space for 5 integers

After this declaration, scores holds 5 integers, all initialized to 0.

String[] names = new String[3];    // 3 Strings, all null
double[] prices = new double[10];  // 10 doubles, all 0.0

new int[5] reserves a fixed block of 5 adjacent memory slots. The size is set once — you cannot expand an array after creation. This is a key limitation to mention early (lists/ArrayLists solve this, but that’s a later topic). Default values: numeric types get 0, booleans get false, object types (String, etc.) get null.

Zero-Based Indexing

int[] scores = new int[5];

scores[0] = 88;   // first element
scores[1] = 74;
scores[2] = 91;
scores[3] = 65;
scores[4] = 78;   // last element (index = length - 1)

Important

Arrays start at index 0, not index 1. An array of length 5 has valid indices 0, 1, 2, 3, 4. There is no scores[5] — that causes an error.

Reading an element:

IO.println(scores[2]);          // prints 91
IO.println(scores[scores.length - 1]);  // prints 78 (last element)

The zero-based rule catches almost every beginner. Reinforce it with the mailbox: mailbox 0 is first, mailbox 4 is last in a 5-box building. The formula “last index = length - 1” is worth writing large on the board. scores.length - 1 as the last-element idiom is something they’ll write hundreds of times.

Array Length

Every array knows how long it is:

int[] scores = new int[5];
IO.println(scores.length);   // prints 5

Note

arr.length is a property, not a method — no parentheses! Compare: str.length() for Strings uses (), but arr.length does not.

Syntax Note
String length str.length() Method — use ()
Array length arr.length Property — no ()

Students who just learned String.length() will immediately write arr.length() — a very common mistake that produces a compile error. The distinction is that arr.length is a public field, not a method call. It’s worth saying out loud: “No parentheses on arrays.” They will thank you later.

Initializer Syntax

When you know the values up front, skip new and list them directly:

int[] scores = {88, 74, 91, 65, 78};

This creates an array of length 5 with those values already in place.

String[] days = {"Mon", "Tue", "Wed", "Thu", "Fri"};
double[] pi   = {3.14159};

You can still use scores.length — it equals 5.

Note

Initializer syntax only works at declaration time. You cannot use {...} to reassign an existing array variable later.

Initializer syntax is concise and widely used. The restriction — only at declaration — is worth stating explicitly because students will try: scores = {1,2,3} after the fact and get a syntax error. If they need to replace all values, they must assign element by element.

Looping Over an Array

The standard idiom for visiting every element:

int[] scores = {88, 74, 91, 65, 78};

for (int i = 0; i < scores.length; i++) {
    IO.println("Score " + i + ": " + scores[i]);
}

Output:

Score 0: 88
Score 1: 74
Score 2: 91
Score 3: 65
Score 4: 78
  • Start at i = 0 (first index)
  • Stop when i < arr.length (not <=!)
  • Access the element as arr[i]

The condition i < arr.length (not <=) is the most important line. Walk through why: if length is 5, valid indices are 0–4. When i reaches 5, i < 5 is false — loop exits safely. i <= 5 would try to access scores[5], which doesn’t exist (ArrayIndexOutOfBoundsException). Burn this pattern into muscle memory: 0 to < length.

Array Algorithms

All the loop patterns from decks 11–13 apply directly to arrays:

Sum:

int sum = 0;
for (int i = 0; i < scores.length; i++) {
    sum = sum + scores[i];
}
IO.println("Sum: " + sum);

Maximum:

int max = scores[0];          // start with the first element
for (int i = 1; i < scores.length; i++) {   // start at 1 (already have 0)
    if (scores[i] > max) { max = scores[i]; }
}
IO.println("Max: " + max);

The max algorithm starts at scores[0] and the loop starts at i = 1 — because we already “considered” index 0. Starting max at 0 would break for all-negative arrays. Starting the loop at i = 0 again would also work but is slightly redundant. Both are fine; teach the “start at first element, loop from 1” pattern as the idiom.

Linear Search

Find the index of a value, or -1 if not found:

int target = 91;
int foundAt = -1;

for (int i = 0; i < scores.length; i++) {
    if (scores[i] == target) {
        foundAt = i;
    }
}

if (foundAt != -1) {
    IO.println("Found at index " + foundAt);
} else {
    IO.println("Not found.");
}

Note

Returning -1 is the Java convention for “not found” in a search. It is a sentinel value (deck 13) — a value that can never be a real index.

Linear search visits every element in order, checking each one. It stops (in this version) only at the end — so if the value appears multiple times, foundAt will hold the LAST occurrence. An early exit (break) can stop at the first occurrence; that’s a refinement to introduce once students are comfortable with the basic pattern.

ArrayIndexOutOfBoundsException

Accessing an index that doesn’t exist crashes the program:

int[] arr = new int[5];   // valid indices: 0, 1, 2, 3, 4

IO.println(arr[5]);       // ✗ crash! index 5 doesn't exist
IO.println(arr[-1]);      // ✗ crash! negative indices don't exist
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: 5

Common causes:

  • Using i <= arr.length instead of i < arr.length
  • Hardcoding an index equal to the length
  • Calculating an index incorrectly

When students see this exception, ask them to find the line number in the error message and look at the index that was used. Is it equal to the length? That’s the <= vs < mistake. Is it negative? They probably subtracted one too many. The stack trace line number is their friend.

Code Example

void printScores(int[] grades) {
    IO.println("Grades:");
    for (int i = 0; i < grades.length; i++) {
        IO.println("  [" + i + "] " + grades[i]);
    }

    int sum = 0;
    for (int i = 0; i < grades.length; i++) {
        sum = sum + grades[i];
    }
    IO.println("Average: " + (sum / grades.length));
}

void main() {
    int[] scores = {88, 74, 91, 65, 78};
    printScores(scores);
}

This combines arrays, methods with parameters (deck 09), and a for loop. Point out that the method accepts int[] as a parameter type — arrays can be passed to methods just like primitives. The average uses integer division; if a more precise average is needed, cast to double first: (double) sum / grades.length.

Common Mistakes

Warning

arr.length without parentheses arr.length() is a compile error — arrays use a property, not a method.

Warning

i <= arr.length in the loop condition This accesses one index past the end → ArrayIndexOutOfBoundsException. Always use i < arr.length.

Warning

Starting at index 1 accidentally If you want every element, start at i = 0. Starting at 1 skips the first.

Warning

Confusing the index with the value scores[i] is the value; i is the position. IO.println(i) prints the index, not the grade.

Walk through each mistake with a short “what would happen?” exercise. Students often get length vs last-index confused even after the first example — it helps to ask them explicitly: “If the array has 5 elements, what is scores.length? What is the last valid index?”

Worksheet

  1. Declare an int array named temps containing the values 72, 68, 75, 80, 71. Use initializer syntax.

  2. Write a loop that prints each element of temps on its own line, formatted as: Day 1: 72, Day 2: 68, etc. (Hint: index + 1 = day number.)

  3. Write a method int sum(int[] arr) that returns the sum of all elements in the array. Call it from main with temps and print the result.

  4. Write a method int min(int[] arr) that returns the smallest element. Test it with temps.

  5. Write a method int countAbove(int[] arr, int threshold) that counts how many elements are strictly greater than threshold. Call it to find how many days were above 72 degrees.

    int[] arr = {10, 20, 30, 40, 50};
for (int i = 1; i <= arr.length; i++) {
    IO.println(arr[i]);
