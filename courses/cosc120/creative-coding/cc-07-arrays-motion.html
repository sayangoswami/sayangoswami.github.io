Step 2 — accumulate the sum and average


You have learned how to walk an array once, accumulating a running sum.



  

    Processing
    

      
      
    

  

  

    
int[] values = { 30, 80, 45, 120, 60, 95, 40 };

void setup() {
  size(400, 220);
}

void draw() {
  background(240);

  int sum = 0;
  for (int i = 0; i < values.length; i++) {
    sum += values[i];
  }
  float avg = (float) sum / values.length;

  int barWidth = width / values.length;
  for (int i = 0; i < values.length; i++) {
    fill(90, 150, 220);
    noStroke();
    rect(i * barWidth, height - values[i], barWidth - 4, values[i]);
  }

  stroke(0);
  float avgY = height - avg;
  line(0, avgY, width, avgY);
}

  

  

    
  

  

    
Errors

    

  




Notice this sketch has two separate loops: the first only computes sum — it draws nothing. The second does the drawing. The black horizontal line is literally avg converted into a y-position. (float) sum is a cast, converting the int sum to a decimal number before dividing, so the average doesn’t get truncated by integer division.






Step 3 — track the max, and highlight it



  

    Processing
    

      
      
    

  

  

    
int[] values = { 30, 80, 45, 120, 60, 95, 40 };

void setup() {
  size(400, 220);
}

void draw() {
  background(240);

  int sum = 0, maxVal = values[0];
  for (int i = 0; i < values.length; i++) {
    sum += values[i];
    if (values[i] > maxVal) maxVal = values[i];
  }
  float avg = (float) sum / values.length;

  int barWidth = width / values.length;
  for (int i = 0; i < values.length; i++) {
    if (values[i] == maxVal) {
      fill(230, 90, 90);
    } else {
      fill(90, 150, 220);
    }
    noStroke();
    rect(i * barWidth, height - values[i], barWidth - 4, values[i]);
  }

  stroke(0);
  float avgY = height - avg;
  line(0, avgY, width, avgY);
}

  

  

    
  

  

    
Errors

    

  




Same accumulator loop, now also tracking maxVal — the same running-max pattern from lecture. The bar matching maxVal gets a different color: both the line and the highlight are array-algorithm results you already know how to compute, now visible as pixels instead of a printed number.






New idea: mousePressed() runs once, not every frame


draw() runs continuously, dozens of times a second — great for things that should constantly update, but wrong for something that should happen exactly once per click. Processing gives you a separate method for that:


void mousePressed() {
  // runs exactly once, the instant the mouse button is clicked
}


draw() keeps running as normal in between clicks; mousePressed() only fires on the click.






Step 4 — swap the first and last value on click


You have learned the in-place reverse algorithm: two indices, one at each end, swapping and moving toward the middle.



  

    Processing
    

      
      
    

  

  

    
int[] values = { 30, 80, 45, 120, 60, 95, 40 };

void setup() {
  size(400, 200);
}

void draw() {
  background(240);
  int barWidth = width / values.length;
  for (int i = 0; i < values.length; i++) {
    fill(70, 150, 110);
    noStroke();
    rect(i * barWidth, height - values[i], barWidth - 4, values[i]);
  }
}

void mousePressed() {
  int temp = values[0];
  values[0] = values[values.length - 1];
  values[values.length - 1] = temp;
}

  

  

    
  

  

    
Errors

    

  




Click the canvas: only the first and last bars swap. draw() doesn’t change at all between clicks — it always just draws whatever values currently holds.






Step 5 — the full reverse



  

    Processing
    

      
      
    

  

  

    
int[] values = { 30, 80, 45, 120, 60, 95, 40 };

void setup() {
  size(400, 200);
}

void draw() {
  background(240);
  int barWidth = width / values.length;
  for (int i = 0; i < values.length; i++) {
    fill(70, 150, 110);
    noStroke();
    rect(i * barWidth, height - values[i], barWidth - 4, values[i]);
  }
}

void mousePressed() {
  reverseArray();
}

void reverseArray() {
  for (int i = 0; i < values.length / 2; i++) {
    int temp = values[i];
    values[i] = values[values.length - 1 - i];
    values[values.length - 1 - i] = temp;
  }
}

  

  

    
  

  

    
Errors

    

  




Same swap as Step 4, now looped from both ends toward the middle — the full reverse algorithm. The loop only needs to go halfway (i < values.length / 2) because each swap handles a pair of elements at once — running it the full length would just swap everything back to where it started.
