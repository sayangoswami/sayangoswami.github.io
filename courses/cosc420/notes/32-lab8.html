Lab 8: Spark on real data

Lab 8: PySpark Analysis of a Real Dataset

Date: November 6
Duration: 50 minutes
Points: 10
Competency: C4.2 — Write PySpark DataFrame transformations including groupBy, orderBy, and joins

Background

Today you apply PySpark to a real dataset: MovieLens (latest-small) — about 100,000 movie ratings collected from real users. You will run multi-step analyses, join two DataFrames, and think about what the data actually tells you.

This is the same dataset and the same two files (ratings.csv, movies.csv) used in the capstone — the loading code and column names here carry over directly, and Task 2’s aggregation is close to the capstone’s Result 2.

Setup

  1. Open the classroom terminal (https://https://hadoop-terminal.sayangoswami.dev/, same login as Lab 4/5). Fetch the dataset directly from there — no need to download it to your laptop and find a way to get it onto the container:

    mkdir -p ~/lab8 && cd ~/lab8
curl -fsSL -o ml-latest-small.zip https://files.grouplens.org/datasets/movielens/ml-latest-small.zip
unzip ml-latest-small.zip

  2. Upload ratings.csv and movies.csv into your own HDFS directory:

    hdfs dfs -mkdir -p /user/<your-username>/lab8
hdfs dfs -put ml-latest-small/ratings.csv /user/<your-username>/lab8/
hdfs dfs -put ml-latest-small/movies.csv  /user/<your-username>/lab8/
hdfs dfs -ls /user/<your-username>/lab8/

  3. Open a new Colab notebook, Lab8_MovieLens, and run Lab 7 Task 4’s three connection cells at the top (pip install + %load_ext, %%spark config, %spark add). The ttyd/HDFS work in Steps 1–2 happens in the classroom terminal; all the PySpark code below runs from this notebook.

Task 1 — Load and Inspect the Data (10 min)

Both files are proper CSVs with headers — no need to specify separators or column names by hand. Remember every cell needs %%spark as its first line (Lab 7 Task 4). Without it, the cell runs in Colab, which can’t see your HDFS files.

ratings = spark.read.csv(
    "hdfs:///user/<your-username>/lab8/ratings.csv",
    header=True,
    inferSchema=True
)

ratings.printSchema()
ratings.show(5)
print(f"Total ratings: {ratings.count()}")
print(f"Unique users:  {ratings.select('userId').distinct().count()}")
print(f"Unique movies: {ratings.select('movieId').distinct().count()}")
movies = spark.read.csv(
    "hdfs:///user/<your-username>/lab8/movies.csv",
