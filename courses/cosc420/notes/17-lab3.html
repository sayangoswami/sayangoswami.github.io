Lab 3: Calling a REST API in Java

Module 1: Concurrency

Published

September 4, 2026

Date: October 2
Duration: 35 minutes Points: 10
Competency: C2.3 — Describe the structure of a REST API and consume one programmatically in Java

Background

REST APIs are the backbone of distributed systems — services talk to each other by sending HTTP requests and receiving JSON responses. Today you will write a Java program that calls a real public API, parses the JSON response, and prints useful information from it.

You will use the Open Library API — no account or API key required.

Setup

You need Java 11 or later (for java.net.http.HttpClient). Check with java -version.

Add the following JSON library to your project:

If using Maven — add to pom.xml:

<dependency>
    <groupId>org.json</groupId>
    <artifactId>json</artifactId>
    <version>20231013</version>
</dependency>

If your IDE of choice doesn’t use Maven — download the org.json jar directly from Maven Central and add it to your project’s classpath/libraries manually.

Put all your code in a single class, LibrarySearch.java, with a main method.

Task 1 — Make a GET Request (10 min)

The Open Library API lets you search for books by title:

https://openlibrary.org/search.json?q=distributed+systems&limit=5

The code below sends a GET request and prints the status code and raw response. Put it in your main method (declare main with throws Exception) and run it.

import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.net.URI;

HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://openlibrary.org/search.json?q=distributed+systems&limit=5"))
    .GET()
    .build();

HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println("Status: " + response.statusCode());
System.out.println("Body:   " + response.body());

Question 1: What status code do you see? What does a 200 status code mean?

Task 2 — Parse the JSON Response (15 min)

This time you write the code. Here is the shape of the response, trimmed to the fields you need:

{
  "numFound": 1234,
  "docs": [
    {
      "title": "Distributed Systems",
      "author_name": ["Maarten van Steen", "Andrew S. Tanenbaum"],
      "first_publish_year": 2002,
      ...
    },
    ...
  ]
}

Using org.json (import org.json.*;), parse response.body() and print a formatted table of the books: title, first author, and first publish year. Your output should look roughly like this:

Title                                              Author                    Year
-------------------------------------------------------------------------------------
Distributed Systems                                Maarten van Steen         2002
...

Things to know:

  • new JSONObject(String) parses a JSON string. A JSONObject has getJSONArray(key); a JSONArray has length() and getJSONObject(i).
  • Not every book has every field. Some have no author_name or no first_publish_year. Your program must not crash on these. Print N/A (or 0 for the year) instead. Look at the opt... methods on JSONObject (optString, optInt, optJSONArray) and see how they differ from the get... methods.
  • System.out.printf("%-50s %-25s %-6s%n", ...) prints left-aligned columns.

Question 2: What does getString do when the field is missing, and what does optString do instead? Which one did you use for each field, and why?

Question 3: Look at the raw JSON from Task 1. Find one field you did NOT print. What is it, and what do you think it represents?

Task 3 — Search for Anything (10 min)

Change your program so the user types the search term instead of it being hard-coded:

  1. Read a search term from the keyboard with a Scanner (e.g. cloud computing).

  2. Build the request URL from that term. Spaces and special characters are not allowed in a URL, so encode the term first:

    String q = URLEncoder.encode(term, StandardCharsets.UTF_8);  // java.net, java.nio.charset

  3. Before parsing, check the status code. If it is not 200, print Error: request failed with status <code> and stop.

  4. If the search finds no books (the docs array is empty), print No results for "<term>" instead of an empty table.

To test step 3, temporarily change the URL path to https://openlibrary.org/does-not-exist. To test step 4, search for nonsense like qwxzv.

Question 4: What status code did you get for /does-not-exist, and what does it mean in HTTP?

Question 5: Remove the URLEncoder.encode call and search for cloud computing again. What happens, and why?
