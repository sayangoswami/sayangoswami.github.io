EL2: Functions, Lists and Dictionaries: A Mini Ratings Pipeline

Background

EL1 covered Python’s syntax and control flow. EL2 covers the other half of what PySpark code relies on: functions (including default arguments and lambda), tuples, lists and list comprehensions, dictionaries, and reading files.

You’ll use these to build a complete small pipeline on an 18-row sample shaped like MovieLens, the dataset from Lab 8 and the capstone:

read files → parse → group by movie → average → join with titles → rank

That’s the same sequence you’ll later write in Spark. Doing it in plain Python first shows what groupBy, avg and join do for you, and why one machine stops being enough (Module 3’s shuffle, and Module 4).

Time: about 45 min of reading + about 75 min on the notebook. The due date is two weeks out because the midterm (Oct 19) falls in this window. Aim to finish it before the Oct 21 Python crash-course lecture.

Exercise 1:

def load_lines(path, skip_header=True):
    lines = []
    with open(path, "r") as f:
        for line in f:
            line = line.strip()
            if line:
                lines.append(line)
    if skip_header:
        lines = lines[1:]
    return lines

Exercise 2:

def parse_rating(line):
    user_id, movie_id, rating, _timestamp = line.split(",")
    return (int(user_id), int(movie_id), float(rating))

def parse_movie(line):
    movie_id, title, genres = line.split(",")
    return (int(movie_id), title, genres.split("|"))

for user_id, movie_id, rating in ratings:

def mean(values):
    return sum(values) / len(values)

stats = {movie_id: (mean(vals), len(vals)) for movie_id, vals in ratings_by_movie.items()}

stats: 1 → (4.25, 4), 2 → (3.0, 3), 6 → (5.0, 1), 16 → (3.5, 2), 32 → (4.5, 3), 47 → (4.5, 4), 999 → (1.0, 1). ratings_by_movie.setdefault(movie_id, []).append(rating) is an equally good one-line version of the grouping.

Exercise 5:

titles = {movie_id: title for (movie_id, title, genres) in movies}
joined = [(titles[m], avg, n) for m, (avg, n) in stats.items() if m in titles]

Question: movie 999 is dropped, because it has a rating but no row in movies.csv, so an inner join has nothing to pair it with. A join that kept it (a left join) would need a placeholder title, such as None or "Unknown", which is what Spark’s how="left" produces as null.

Exercise 6:

def top_n(rows, n=3, min_count=2):
    eligible = [row for row in rows if row[2] >= min_count]
    return sorted(eligible, key=lambda row: (row[1], row[2]), reverse=True)[:n]

Result: Seven (4.5, 4), Twelve Monkeys (4.5, 3), Toy Story (4.25, 4). Question: with min_count=1, Heat wins with a single 5.0 rating. One person’s opinion isn’t evidence that a film is good. A minimum count (≥ 50 in the capstone) keeps films with too few ratings to trust from topping the chart.

Reflection: the pattern to look for: 1. Map = Exercises 2–3 (each line → (movie_id, rating)). Shuffle = Exercise 4b (group by movie_id). Reduce = Exercise 4c (mean per group). Exercise 5’s join is the extra step MapReduce makes awkward and Spark makes one line. 2. The first line to cause trouble is load_lines / the ratings = [...] comprehension (or ratings_by_movie), because it holds every line in memory at once on one machine. At 100 GB that exceeds a laptop’s RAM, and even if it fit, one CPU would process it serially. Spark splits the file into partitions across machines and streams them.
